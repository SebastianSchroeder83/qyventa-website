# Qyventa GitHub Pages

## Veröffentlichung

1. Lade `index.html`, `qyventa-icon.png` und `qyventa-wordmark.png` in dein GitHub-Repository.
2. Öffne in GitHub: **Settings → Pages**.
3. Wähle unter **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. Speichern. Nach kurzer Zeit ist die Seite online.

Hinweis: Die Warteliste ist aktuell nur eine Demo und speichert E-Mail-Adressen lokal im Browser.
Für echte Anmeldungen muss später z. B. Formspree, Brevo, Mailchimp, Supabase oder Firebase angebunden werden.
